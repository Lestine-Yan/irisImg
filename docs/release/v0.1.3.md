# irisImg v0.1.3 发布说明

> **版本**：v0.1.3
> **发布日期**：2026-11-16
> **产物**：`irisImg-0.1.3-linux-amd64.tar.gz`

v0.1.3 是一次**前端界面与品牌一致性版本**。登录页、登录到后台的曲线加载过渡、后台整体 UI、页面标题与 favicon 全部更新；后端业务、接口、配置与数据库均无变更。

---

## 一、登录页与加载过渡

### 登录页重设计

- 保留 `iris / Img` 两行字标，改为近黑 + 紫蓝渐变，并补充「轻量、高性能的私人对象存储」定位文案与轻量 / 高性能 / 私有三项能力。
- 重做背景：去掉旧版大色块斜切，改为暖白纸色、细网格、轨道圆、花瓣曲线与少量金色花蕊；`flower.webp` 以透明通道 + multiply 融入纸色。
- 登录卡片改为半透明玻璃表面，补充密码显隐、字段标签、错误态、`autocomplete` 与 ARIA 属性。
- 移动端压缩字标、隐藏能力列表，让登录表单更早进入首屏。

### 登录到后台的曲线过渡

- 新增全屏加载层：品牌标记、`正在进入工作台`、细进度线与自托管页脚。
- 四条曲线先在加载页中央漂浮，登录成功后 900ms 内插值到后台背景的落点，并随背景淡出，完成从加载页到后台的 UI 过渡。
- 加载层与后台上层使用同一份曲线控制点，避免过渡结束跳线。
- 过渡期间锁定页面滚动；`prefers-reduced-motion` 下跳过漂浮与插值。

## 二、后台 UI 重设计

- 后台整体换成与登录页同源的暖白纸色、细网格、径向柔光、轨道线与落定曲线。
- 侧边栏按 Overview / Library / System 分组：`< xl` 收为 76px 图标栏，`>= xl` 为 264px 完整栏；激活项使用白色玻璃胶囊 + 左侧紫条。
- 统一页面标题、统计卡、趋势卡、筛选栏、表格容器、配置分组、图片 / 音频卡片与弹窗表面为玻璃卡片样式；图片 / 音频网格使用无 backdrop blur 的扁平版本，控制长列表滚动开销。
- 仪表盘、内容中心、日志中心、APIkey 管理、系统配置全部接入新表面；窄屏下用户区与退出入口仍保留。

## 三、品牌图标、页面标题与文档

- 新增透明底双瓣 favicon：`favicon.svg` 为主，`favicon.ico` 提供 16/32/48/64/128 fallback，`apple-touch-icon.png` 为 180×180。
- 全站页面标题设为 **`IrisImg 你的私人存储空间`**，并补充 description。
- README WebUI 速览加入加载过渡说明，使用无头浏览器重新截取登录、加载、仪表盘、内容中心、日志中心、APIkey 管理页面；技术栈徽标之间补充空格、保持同一行。
- 同步布局、侧边栏、用户区、登录链路、过渡组件、页面与公共组件文档；新增过渡状态机、曲线数据与后台背景文档。
- `scripts/build-release.sh` 版本号改为读取最近 git tag（`v0.1.3` → `0.1.3`），仍支持 `VERSION=` 覆盖；`docs/deploy.md` 同步版本优先级说明。

## 五、升级注意（v0.1.2 → v0.1.3）

1. **配置零变更**：无新增或修改配置键，`config.yaml` 原样沿用。
2. **数据库零变更**：无 schema 迁移。
3. **接口零变更**：路由、DTO、错误码、鉴权与审计事件均不变，后端无需重新适配。
4. **替换前端产物**：将 `web/` 整体替换为 v0.1.3 的 SPA 静态产物，并刷新浏览器缓存即可看到新 UI 与 favicon。
5. **后端二进制**：本版本不含后端代码变更，可沿用现有二进制；release 包内仍会包含按 Go 1.26.10 重新构建的后端二进制。
6. **favicon 缓存**：若浏览器标签仍显示旧图标，强制刷新或清理站点图标缓存。

## 六、验证

```bash
cd frontend && pnpm build
```

- `pnpm build` 通过。
- 无头 Edge 在 1440×900 与 390×844 下验证登录、加载过渡、仪表盘、内容中心、日志中心与 APIkey 页面；窄屏侧边栏收为 76px 图标栏，页面无横向溢出。
- 无头 Edge 校验 `document.title` 与 `/favicon.svg`、`/favicon.ico`、`/apple-touch-icon.png` 均返回 200。
- 后端无代码变更；发布 workflow 仍会执行 `go vet ./...` 与 `go test ./...` 作为发布门禁。

## 七、说明

- 本版本仍无暗色模式，窄屏后台为 76px 图标栏而非抽屉导航。
- Apple touch icon 为透明底；若 iOS 主屏自动铺黑底，需要另做不透明背景版本。
