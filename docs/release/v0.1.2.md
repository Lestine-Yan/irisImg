# irisImg v0.1.2 发布说明

> **版本**：v0.1.2
> **发布日期**：2026-10-22
> **产物**：`irisImg-0.1.2-linux-amd64.tar.gz`

v0.1.2 是一次**安全性维护版本**，不含业务逻辑或接口变更。核心是把 Go 工具链从 `1.26` 提升到 `1.26.10`，纳入 `crypto/x509` 对 CVE-2026-111943 的紧急修复，并同步刷新 README 与部署文档中的版本声明。

---

## 一、安全更新

### CVE-2026-111943：eMudhra 中间证书信任移除

- **影响**：eMudhra 的 8 张中间 CA（EM DV/OV/EV TLS CA G3B/G3C、EM OV CS CA G3B/G3C）私钥可从证书本身恢复，Mozilla 于 2026-10-17 报告，eMudhra 次日吊销。
- **Go 修复**：自 Go 1.26.10 / 1.27.3 起，`crypto/x509.Verify` 在构链结果中按**公钥 SHA-256** 过滤上述中间证书，命中即以 `x509: no valid chains built` 失败；无开关可绕过，自定义 `Roots` 与 macOS/Windows 平台验证器同样生效。
- **本版本处理**：`backend/go.mod` 的 `go` 指令固定为 `go 1.26.10`。CI（`setup-go` 读取 `go-version-file: backend/go.mod`）与本地 `GOTOOLCHAIN=auto` 均据此选用精确补丁版本；只有用该版本重新构建的二进制才携带修复。
- **实际暴露面**：irisImg 后端当前没有任何出站 HTTPS 请求或 `crypto/x509` 校验逻辑（已全量检索确认），运行时不受该漏洞直接影响；本次升级意在保持工具链合规、消除扫描告警，并为后续可能的出站请求预留安全基线。

## 二、变更记录（Changelog）

- `backend/go.mod`：`go 1.26` → `go 1.26.10`（依赖与 `go.sum` 均无变化）。
- `README.md`：Go 徽章更新为 `1.26.10`，当前版本指向 v0.1.2。
- `docs/deploy.md`：工具链说明固定为 `go 1.26.10`，补充 CVE 来源与「安全补丁须重新构建产物」的约束。

## 三、升级注意（v0.1.1 → v0.1.2）

1. **配置零变更**：无新增或修改配置键，`config.yaml` 原样沿用。
2. **数据库零变更**：无 schema 迁移。
3. **接口零变更**：路由、DTO、错误码、审计事件均不变，前端无需重新适配。
4. **必须替换二进制**：安全修复只存在于用 Go 1.26.10 重新构建的产物中，请整包覆盖 `irisImg` 可执行文件（`config/config.yaml` 与 `data/` 不在包内、不受影响）。
