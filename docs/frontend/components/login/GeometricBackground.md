# `frontend/app/components/login/GeometricBackground.vue`

登录页全屏背景组件，由「留白底色 + 细线 SVG + 鸢尾花原作」三层构成。

## 职责

- 以 `fixed inset-0 z-0` 覆盖整个视口，位于内容层（`z-10`）之下。
- 不使用大色块拼接，改用低透明度径向光晕、细网格、轨道圆与花瓣曲线营造简约现代的留白氛围。
- 将 `public/flower.webp` 作为右上角的大幅背景画，保留透明通道，并用 `mix-blend-mode: multiply` 让花瓣与纸色、线稿自然融合。

## SVG 视觉元素

- 底色：`#F7F7F2` 暖白。
- 径向光晕：右上浅天蓝（`#86C9EC`）、下方紫罗兰（`#6D4FD8`）、左上少量金色（`#F4C430`），透明度均控制在 0.1 左右。
- 细网格：72×72 的 1px 网格，通过径向渐变遮罩只保留画面中部，避免满屏格子。
- 轨道圆：以 `(1128, 408)` 为中心的四层细圆，最大半径 452，使用紫罗兰与浅天蓝的低透明度描边。
- 花瓣曲线：从画面左下延伸至右上花心的三条贝塞尔曲线，呼应鸢尾花瓣与花茎。
- 点缀：稀疏紫点、两个十字标记、三根金色花蕊短线。

## 花朵图层

- 图片：`/flower.webp`（1440×1440，鸢尾花水彩插画；由原始 PNG 压制、保留透明通道的 WebP，约 180 KB）。
- 定位：右上角，`h-[114vh] w-[114vh]`，最大 1100px，`-right-[6%] -top-[17%]`。
- 混合：`mix-blend-multiply` + `opacity: 0.86`，透明背景与纸色自然叠加，只突出花瓣与花茎。
- 遮罩：径向渐变柔化四周边缘，避免出现图片边界。
- 动效：`flower-drift` 26s 缓慢漂移缩放；`prefers-reduced-motion` 下关闭。
- 移动端（`< md`）隐藏花朵，仅保留细线背景，避免与登录卡片抢视觉。

## 层级注意事项

- 页面根节点不能再设置不透明背景色，否则会盖住本组件的 `z-0` 图层。
- 组件本身 `pointer-events-none`、`aria-hidden="true"`，不参与交互与读屏。

## 与其它文件的关系

- 被 `frontend/app/pages/index.vue` 引用，作为登录页最底层视觉层。
- `flower.webp` 位于 `frontend/public/`，构建时复制到产物根路径。

## 修改建议

- 花朵的 `opacity`、尺寸与右上偏移共同决定构图；增大花朵会加强视觉冲击，但需同步提高登录卡片的背景不透明度以保证可读性。
- 若更换花朵图片，优先选择纯白或透明背景、主体偏右上的素材，并重新检查 `multiply` 效果。
- 细线颜色与透明度已压得很低，调整时保持「近看有细节，远看是留白」的尺度。
